# 墨枢 iPad 版 · 安装说明（Mac）

iPad 上是一个完整的原生 App（Capacitor 包壳），界面与功能与桌面版同一套代码：正文编辑、分卷分章、大纲、版本历史、无限画布、设定库、AI 助手、字数统计、检索等全部保留。
数据默认存在 iPad 本地，改动后自动定时同步到你自己的墨枢服务器。

## 一、准备

- 一台 Mac（macOS 13 及以上），从 App Store 安装 **Xcode**，首次启动按提示安装附加组件
- 一根数据线 + 你的 iPad（iPadOS 14 及以上）
- CocoaPods（多数 Mac 已自带，没有就装一个）：
  ```bash
  sudo gem install cocoapods
  # 或
  brew install cocoapods
  ```

## 二、装到 iPad

1. 解压交付包，进入 `mushu-ipad` 目录，安装依赖：
   ```bash
   npm install
   ```
   国内网络慢可以加镜像：`npm install --registry=https://registry.npmmirror.com`

2. 安装 iOS 原生依赖：
   ```bash
   cd ios/App
   pod install
   ```
   Apple 芯片 Mac 若在 pod install 阶段报架构错误，可用 `arch -x86_64 pod install` 重试。

3. 用 Xcode 打开工作区（**必须是 .xcworkspace**）：
   ```bash
   open App.xcworkspace
   ```

4. 在 Xcode 里配置签名：
   - 左侧选中 `App` 工程 → `TARGETS` 下的 `App` → `Signing & Capabilities`
   - `Team` 选择你自己的 Apple ID（没有就先在 Xcode → Settings → Accounts 添加）
   - 把 `Bundle Identifier` 改成你自己的唯一值，例如 `com.你的名字.moshu`
   - 勾选 `Automatically manage signing`

5. 用数据线连上 iPad（iPad 上如弹出「信任此电脑」请点信任），在 Xcode 顶部设备列表选中这台 iPad，点 ▶ 运行。

6. 若 iPad 提示「不受信任的开发者」：
   iPad → 设置 → 通用 → VPN 与设备管理 → 选中你的开发者证书 → 信任。

> 用免费 Apple ID 签名，App 有效期 7 天，到期后连 Mac 再 Run 一次即可；付费开发者账号有效期为 1 年。

## 三、首次使用

1. 打开「墨枢」→ 右上角 `≡` 菜单 →「服务器连接…」，填写：
   - 服务器地址：`https://mushu.sfangjie.cn`
   - 访问密码：与桌面端 / 网页端一致
   - 点「保存并继续」，会先做一次连通性校验
   - 暂时不想同步可以点「稍后设置（仅本地）」，之后随时在同一个菜单里补填

2. （可选）`≡` →「设置…」→ AI：填 DeepSeek API Key。
   密钥只保存在你自己的服务器上，iPad 本地不落明文。

3. 写作时的数据流：
   - 所有内容先写 iPad 本地（App 沙盒内），8 秒防抖落盘
   - 定时（约 3 分钟）与切后台时，与服务器做增量同步
   - 顶栏会显示「已同步 HH:MM」/「同步失败」/「仅本地」

## 四、注意事项

- 卸载 App 会连带删除 iPad 本地数据，请确认服务器上已有同步副本再卸载；也可以用 `≡` →「设置…」→ 备份缓存 把作品导出留存。
- 换台电脑或继续开发：需要完整的墨枢源码仓库，在根目录执行 `npm run build:mobile` 重新生成 `mobile/www`，再执行 `npx cap sync ios`。
- 同步为「本地优先」：iPad 上的改动会推到服务器，服务器上被删掉的文件不会反向删除本地文件。
